# Set 7 case photographs

The WebP files are presentation-size derivatives of the sources below. Each was downloaded,
decoded, and inspected on Nov 19, 2026. Captions should name the pictured object without
claiming that it proves the wider ethics argument on its slide.

| File | Suggested existing slide | Accurate native caption | Source and reuse terms |
| --- | --- | --- | --- |
| `titan_lakes.webp` | `14. Titan Is a Real Chemistry Question` | Cassini radar image of lake forms on Titan. Radar reflectivity shows surface structure, not life. | [NASA JPL, PIA01943](https://photojournal.jpl.nasa.gov/catalog/PIA01943), Cassini radar. Educational use with NASA acknowledgement under [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). |
| `hela_fluorescence.webp` | `26. HeLa and Consent` | Cultured HeLa cells. Golgi-targeted fluorescent protein is orange, microtubules green, and DNA cyan. | [NIH NIGMS image 3522](https://www.nigms.nih.gov/image-gallery/3522), source NCMIR. [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/). Credit NIGMS and NCMIR. |
| `papaya_ringspot.webp` | `7. A Papaya Grower Faces Ringspot Disease` | Papaya leaf mosaic attributed to papaya ringspot virus. This is a symptom photograph, not a field-trial result. | [Plant pests and diseases, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Papaya_(Carica_papaya)-_Papaya_ringspot.jpg), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). |
| `prosthetic_arm.webp` | `34. The Same Graft, Different Goals` | Historical photograph of a person using a left-arm prosthesis. A prosthesis, a transplant, and a composite allograft raise different questions. | [NLM image 101406686](https://resource.nlm.nih.gov/101406686). NLM believes the item is public domain. |
| `viking_footpad.webp` | `14. Viking Found a Signal on Mars` | Viking Lander 1's footpad and nearby Martian surface. A mission photograph documents the landing site, not a biological finding. | [NASA JPL, PIA10738](https://photojournal.jpl.nasa.gov/catalog/PIA10738). Educational use with NASA acknowledgement under [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). |
