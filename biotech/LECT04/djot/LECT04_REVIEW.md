# Biotechnology Lecture 04 conversion

Lecture 04 is organized under `biotech/LECT04/`. Canonical Djot and selected instructor figures
live in `djot/`; original ODP, PDF, and student-presentation sources from 2022-2026 live in `old/`.

The [Set 3 master](lect04c-talking_points_set_3.djot) compiles the four talking-point chapters
into one ODP, in the order below. Edit the chapter files separately. Folder builds select the
master once, alongside the announcements and individual-project decks. The combined ODP has
389 slides, including six hidden answer pages, and one final THE END slide.

```bash
source source_me.sh && python3 deck_tools.py build \
  biotech/LECT04/djot/lect04c-talking_points_set_3.djot --format odp
```

The result is `output/odp/lect04c-talking_points_set_3.odp`. Older separate chapter artifacts
may remain in the output directory; they are not regenerated by folder builds.
