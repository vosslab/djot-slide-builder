# *Understanding Branch Points*

@left

![Gene tree diagram](assets/lect12b-gene_trees/phy_b_branch_points.drawn.svg)

@right

- [*Branches*]{color=#355269 underline=true} [reflect evolutionary paths from common ancestors.]{color=#355269}
- [Each divergence event is marked by a]{color=#355269} [*branch point*]{color=#355269 underline=true} [in the tree.]{color=#355269}
- [These points signify the splitting of one group into two distinct lines.]{color=#355269}
- [Interpretation of these points helps trace species' evolutionary history.]{color=#355269}


- [https\://en.wikipedia.org/wiki/Phylogenetic\_tree](https://en.wikipedia.org/wiki/Phylogenetic_tree)

# *Tracing Common Ancestors*

@left

![Gene tree diagram](assets/lect12b-gene_trees/phy_b_mrca.drawn.svg)

@right


- [Closeness of species determined by recency of common ancestors.]{color=#55215B}
- [To find the most recent common ancestor (MRCA), &#8220;walk backwards&#8221; to where species lines converge.]{color=#55215B}
- [Example\: A and B share a more recent ancestor than B and C, indicating closer relation.]{color=#55215B}
- [Understanding MRCA is crucial for interpreting evolutionary relationships.]{color=#55215B}

- [https\://en.wikipedia.org/wiki/Most\_recent\_common\_ancestor](https://en.wikipedia.org/wiki/Most_recent_common_ancestor)

=== layout: one-panel

# *UPGMA Distance Method*

@body

- UPGMA\: [*Unweighted Pair Group Method with Arithmetic Mean.*]{underline=true}
- Constructs tree by grouping sequences based on minimum distance.
- Assumes a molecular clock\: constant rate of evolution across all lineages.
- Useful for simple, quick phylogenetic analysis with less complexity.
- [https\://en.wikipedia.org/wiki/UPGMA](https://en.wikipedia.org/wiki/UPGMA)

# Neighbor-Joining Distance Method

@body


- Neighbor-Joining\: A bottom-up clustering method for tree construction.
- Does not assume a constant rate of evolution, unlike UPGMA.
- Iteratively joins a pair using an adjusted NJ score, then recalculates distances.
- Preferred for its accuracy in more complex phylogenetic analyses.
- Requires more math equations than UPGMA.


=== layout: two-panels

# Neighbor-Joining Distance Method: Step 1

@left

| | A | B | C | D |
|---|---|---|---|---|
| A | 0 | 7 | 8 | 11 |
| B | 7 | 0 | 5 | 8 |
| C | 8 | 5 | 0 | 5 |
| D | 11 | 8 | 5 | 0 |

- Choose A and B using the adjusted NJ score. AB and CD tie; retain the source AB choice.

# *Character-Based Methods*

@left

- Analyze specific genetic characters or sequences.
- Include methods like [Maximum Parsimony]{color=#00A933} and [Maximum Likelihood]{color=#00A933}.
- Focus on evolutionary changes in genes or morphological features.
- Provide detailed insights, suitable for various data complexities.

@right

- Character-based methods analyze specific genetic or morphological characters.
- Distance-based methods calculate overall genetic distances between sequences.
- Character-based (e.g., Maximum Parsimony, Maximum Likelihood) offer detailed insights.
- Distance-based (e.g., UPGMA, Neighbor-Joining) are efficient for large datasets.
- Choice depends on data complexity and desired level of detail in analysis.

=== layout: one-panel

# *The Parsimony Method*

@body

- Seeks the simplest explanation with the fewest evolutionary changes.
- Ideal for datasets where evolutionary events are relatively infrequent.
- Minimizes assumptions about evolutionary rates and patterns.
- Balances between simplicity and explanatory power in tree construction.

=== layout: one-panel

# *Parsimony Example*

@body

![Gene tree diagram](assets/lect12b-gene_trees/phy_b_parsimony.drawn.svg)

- there are various trees that could explain the phylogeny of the sequences [AAG, AAA, GGA, AGA]{color=#00A933} including the two above.
- parsimony prefers the first tree because it requires fewer substitution events (less [red letters]{color=red}\: 3 vs. 4)

=== layout: one-panel

# *Maximum Likelihood in Phylogenetics*

@body

- Evaluates probability of observed data under different tree hypotheses.
- Utilizes statistical models to estimate tree likelihood.
- Suitable for complex datasets requiring detailed evolutionary models.
- Computationally intensive, offering nuanced understanding of relationships.

=== layout: one-panel

# Bayesian Inference in Phylogenetics

@body


- Bayesian methods incorporate prior knowledge with observed data.
- They estimate the posterior probability of trees using statistical models.
- Highly flexible and can incorporate various types of evolutionary models.
- Provides a probabilistic framework for tree estimation and hypothesis testing.
