# *Gene Trees by Distance Method*

@body

- Differences can be a measure of evolutionary separation.
- Two problems with this assumption\:
  - 1. mutations are chance and differences are not really correlated with evolutionary time.
  - 2. some mutations increase survival rate and have better chance of being [*fixed*]{underline=true}.

# Key Takeaways

@body

- Start with the smallest distance in the matrix.
- Update the matrix after each merge.
- Keep earlier branches when adding a new cluster.
- Check the final tree against the original distances.
