# Repository color assignments

Choose colors from [COLOR_PALETTE.md](COLOR_PALETTE.md) and use these assignments for the local
materials named below. Reuse each assignment in related figures, labels, tables, and explanations.

For slide layout, emphasis, and reveal timing, see
[slide-specs/COLOR_GUIDE.md](slide-specs/COLOR_GUIDE.md).

## Announcement emphasis

Use Red Dark for assessment reminders, the icebreaker, policy emphasis, contact labels, and
Biochemistry Lab promotions in Genetics 11A and equivalent emphasis in Biostatistics 12A.
Use the shared contact and registration fragments for these slides across courses.
Preserve the icebreaker's typeface and size.

## Procedure sequences

For four steps, use Red, Green, Blue, and Purple. For six, use Red, Dark orange, Dark yellow,
Green, Blue, and Purple. Use the Dark shades. Repeat each roadmap with the same assignments and
match cross-references to its steps. Track roadmap steps and data classes by their own keys.

For other lengths up to 14, spread the choices across the ordered hue families, including the
first and last. For longer sequences, repeat the sequence and retain numbered step labels.
In randomized ordering questions, assign colors to the displayed choices after shuffling.

Use each pair's recombinant color for its rows, labels, map lines, results, and final percentage.
Use the listed fills in tables and allele comparisons. Keep the covered gene column gray even
where it crosses highlighted rows. Preserve the timing of classification and result reveals.

| Meaning | Labels and lines | Fill |
| --- | --- | --- |

## Existing figure tools

The SVG shade helper [../svg_tools/palette.py](../svg_tools/palette.py) derives figure lightness
at 90%, 75%, 55%, 35.3%, and 20% in its existing output. Use the shared hex table for new
authored assignments. The QPM color wheel is available for exploring hue spacing and for
reproducing existing outputs that use its CAM16 dark, light, or extra-light variants.
