# Slide specifications

These documents define slide authoring, teaching, and review. Start with
[AUTHORING_GUIDE.md](AUTHORING_GUIDE.md) for the overview and source-authority rules.
Current instructor instructions and [../HUMAN_GUIDANCE.md](../HUMAN_GUIDANCE.md) take precedence.

- [AUTHORING_GUIDE.md](AUTHORING_GUIDE.md): source organization, layouts, typography, and artifacts.
- [COLOR_GUIDE.md](COLOR_GUIDE.md): meaningful emphasis, consistent associations, and reveals.
- [VOICE_GUIDE.md](VOICE_GUIDE.md): wording, notation, humor, and preservation of teaching voice.
- [PEDAGOGY_GUIDE.md](PEDAGOGY_GUIDE.md): teaching sequences, worked examples, questions, and study use.
- [QUESTION_LAYOUTS.md](QUESTION_LAYOUTS.md): questions to ponder, icebreakers, and choice/answer layouts.
- [DJOT_SLIDE_SYNTAX.md](DJOT_SLIDE_SYNTAX.md): supported Djot syntax and layout contracts.
- [TABLE_AUTHORING_GUIDE.md](TABLE_AUTHORING_GUIDE.md): native table presets, local formatting, and recipes.
- [SVG_DIAGRAMS.md](SVG_DIAGRAMS.md): diagram composition, editable labels, and asset requirements.
- [ANNOUNCEMENT_DECK_GUIDE.md](ANNOUNCEMENT_DECK_GUIDE.md): weekly structure and course exceptions.
- [SLIDE_VISUAL_REVIEW_RUBRIC.md](SLIDE_VISUAL_REVIEW_RUBRIC.md): advisory rendered-slide review.

The vendored [../COLOR_PALETTE.md](../COLOR_PALETTE.md) and
[../COLOR_CONTRAST_ACCESSIBILITY.md](../COLOR_CONTRAST_ACCESSIBILITY.md) stay in their managed
locations. Reference their values and policy rather than copying them into these guides.

Build commands remain in [../USAGE.md](../USAGE.md); conversion workflow remains in
[../SLIDE_CONVERSION_CHECKLIST.md](../SLIDE_CONVERSION_CHECKLIST.md).
