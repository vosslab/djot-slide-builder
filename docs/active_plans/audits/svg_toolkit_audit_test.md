It tests a synthetic filesystem and tests `native_export.find_repo_root()` rather than directly asserting the changed `djot_sources.repository_root()` fallback. Keep the meaningful nearest-root and symlink assertions; move the synthetic fallback check to temporary verification or test the actual fallback in an isolated location without patching a global primitive. No new permanent test is proposed without a demonstrated regression and a stable isolated setup.
- **Low — permanent examples pin one-time implementation proof:** `tests/test_svg_binding.py:32` locks authored example contacts; `tests/test_svg_chromosomes.py:215-244` locks a real data inventory and source-specific coordinates; `tests/test_svg_import.py:40-44` depends on a lecture asset and generated metadata. Move these examples to temporary checks unless those exact examples/data are deliberate permanent product contracts. Underlying behavior has focused tests.
