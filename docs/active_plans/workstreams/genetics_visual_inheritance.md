Original SVG clipart, biological illustrations and scientific drawings are the deliverable.
Source images establish scientific facts and teaching purpose, not a visual template. Artists
may change composition, perspective, silhouette and explanatory emphasis. Keep strong existing
art; refine or redesign demonstrated weaknesses using the provisional visual language developed
from reviewed equipment, organism and diagram examples. See
[genetics_visual_workstreams.md](genetics_visual_workstreams.md) for current assignments.
Keep source facts, named examples, data, prose, questions, hidden states and reveal order.
Use existing native tables/styles as resources. In composite figures replace the graphic only;
retain the original composite when separation requires independent content reconstruction.
Change labels/layout only as needed to integrate the drawing. A slide split needs a concrete
drawing-placement reason. No independent table, math, worksheet or curriculum work is included.

Use self-contained SVG with editable geometry and live short labels. Check source invariants,
then inspect the actual ODP/PDF drawing and adjacent states through the serialized export owner.
Retain original assets and excluded working code/art. All delegates use Astra.

## Drawing preservation details

- Preserve named organisms and recognizable flower/seed/animal anatomy. Keep 705/224 observed
  counts, P/F1/F2 disclosure, cross sexes, trait symbols and existing genotype/phenotype examples.
- Preserve each pedigree's people, sex, affected/carrier marks, connections, labels and staged
  answers. Pedigrees are included; gene/species phylogenies are excluded.
- Preserve chromosome/chromatid counts, homolog colors, crossover locations, cell divisions and
  existing gamete outcomes. Source-label recovery is only for the drawing being replaced.
- In a mixed cross/data figure, replace the organism or chromosome graphic while preserving
  the original table and problem. Punnett tables, probability equations, chi-square worksheets,
  independent problem text and native-table transcription are not drawing tasks.
- Existing suitable illustration assets remain usable; drawing work does not authorize a new
  sequence, solution, distribution calculation or statistical correction.

## Completion boundary

minimal integration. Do not treat XML validity or source-equivalent contours as art completion. Preserve not-targeted content
and deferred gene trees; unresolved drawing evidence means retain the source with a reason.
Final consumer exports and `source ./source_me.sh && pytest tests/` belong to the existing
plan/ledger. ASCII Djot permits character references; SVG must remain valid XML.
